# Online Retail Analysis

Analysis of 540k+ online retail transactions using Python (pandas, matplotlib).

## What this project does
- Cleans the transaction data (removes missing customers and returns)
- Analyzes monthly revenue trends and top countries
- Segments customers with RFM (Recency, Frequency, Monetary)

## Dataset
UCI Machine Learning Repository: Online Retail dataset.

## How to run
Open `Online_Retail_Analysis.ipynb` in Google Colab, upload the Excel file, and run all cells.# online-retail-analysis
